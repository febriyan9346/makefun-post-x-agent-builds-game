A 36-second vertical video about an AI coding agent building the tiny browser game Meteor Dodge from one prompt — watch the prompt, the agent working, and the finished game running, ending with make.fun's referral end card. The game itself (game.html) is playable in any browser: steer the rocket, dodge the meteors, survive 60 seconds.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
